Welcome to my **90-day structured journey** into production-grade DevOps and Site Reliability Engineering (SRE). 

This repository is a living portfolio where I document my transition from just "using tools" to "engineering reliable systems." Every day, I will document the core concepts, architectural diagrams, hands-on labs, and troubleshooting scenarios.

## 🎯 The Mission
The goal of this journey—inspired by the **#90DaysOfDevOps** initiative—is to master:
*   🚀 **Production-focused DevOps:** Moving beyond basics to scalable solutions.
*   🏗️ **Infrastructure as Code (IaC):** Mastering Terraform and Ansible for reproducible environments.
*   📦 **Container Orchestration:** Deep diving into Kubernetes (K8s) and Docker.
*   🚨 **SRE Principles:** Focusing on observability, reliability, and incident response.
*   🔄 **CI/CD Mastery:** Building robust pipelines with Jenkins, GitHub Actions, or GitLab CI.
