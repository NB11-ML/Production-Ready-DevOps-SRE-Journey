# 🐧 🔗 Day 14: Linux Networking for DevOps & SRE

Welcome to **Day 14** of the Production-Ready DevOps & SRE Journey! 🚀

This module covers essential Linux networking concepts and diagnostic tools required to design, secure, and troubleshoot cloud infrastructure and microservices.

---

## 📌 What's Covered

* **Networking Models:** Understanding OSI (7 Layers) & TCP/IP models.
* **Core Concepts:** IP Addressing, Private Ranges (RFC 1918), Subnetting/CIDR, and DNS.
* **CLI Toolkit:** Essential command-line utilities (`ip`, `dig`, `ss`, `ping`, `traceroute`, `curl`, `nc`).
* **SRE Triage Workflow:** Step-by-step diagnostic strategy for debugging connectivity issues across Layer 3 to Layer 7.
